GuidePLC Ladder Logic Trainer

This is a real PLC, not an animation. The ladder program sits on the left, the live intersection (or motor) on the right, and every tag value underneath.

The scan cycle

The PLC never stops looping. Every lap — one scan — it does three things, strictly in this order:

  1. Reads every input into a snapshot: the input image table.
  2. Solves the rungs top-to-bottom, left-to-right, from that snapshot.
  3. Writes every output at once, from the output image table.

So pressing a button does nothing until the next input read — and a bit written by rung 5 reaches rung 6 in the same scan, but rung 4 only on the next one.

Step mode — what no physical trainer can show you

Press ⏸ Pause, then Step Scan to advance exactly one scan at a time with both image tables on screen. Rows flash when a bit changes, so you can see precisely when it changed. Keyboard: Space to run or pause, . to step one scan.

Challenges and troubleshooting

Challenges gives you four graded builds — motor seal-in, delayed start, the stoplight from a written spec, then the crosswalk. Build yours in the editor and the grader runs it against a scripted input sequence, then tells you which step failed and when.

Troubleshoot injects one of eleven faults into a working program. Diagnose it from the intersection's misbehaviour and the ladder, then reveal the explanation.

Getting started

  1. Pick a program. 5 — Motor Seal-In is the quickest way in; 1 — Basic Timed Stoplight is the full thing.
  2. Press an input on the panel — START, STOP, a pedestrian button, a car sensor — and watch the live power path light up through the ladder. Green means true.
  3. Pause and step a few scans with the watch window open.
  4. Click any instruction for a plain-English account of what it is doing right now.
