How to use Ladder Lab

Start in Trainer. The ladder program is on the left; the live intersection or motor is on the right.

  1. Choose a program. Program 5 is the fastest introduction; Program 1 is the full stoplight.
  2. Press an input on the simulator—START, STOP, a pedestrian button, or a car sensor—and watch the highlighted path through the ladder.
  3. Pause, then use Step Scan to see the PLC read inputs, solve rungs top-to-bottom, and update outputs.
  4. Use Challenges to build a program or Troubleshoot to diagnose an injected fault.

What to watch

Green instructions are true. The Watch Window shows the input, internal-bit, timer, and output image tables; changed values flash.
