Candidate model

All plotted candidates use v = Vmax·S / (a·Km + b·S). Competitive: a=3, b=1. Uncompetitive: a=1, b=3. Pure noncompetitive: a=b=3.

Teaching boundary: the competitive/uncompetitive tie at S=Km is deliberately produced by this matched-factor synthetic set. It is not a general diagnostic rule for real inhibition.

These are simplified steady-state initial-rate patterns. They omit mixed, tight-binding, partial, time-dependent, and other inhibition behavior.

Transfer: choose the next useful measurement

Suppose an initial result at S = Km was 25.0. It leaves the competitive and uncompetitive synthetic patterns tied in this model. Which one additional substrate measurement would eliminate a candidate? Several choices can be equally informative here.

How to investigate

  1. Read the three plotted candidate patterns; the mystery sample’s generating pattern is not shown.
  2. Choose a substrate concentration and run an exact initial-rate assay. You have four distinct concentrations.
  3. Compare each observed point with all candidate curves. A match at one point may still be ambiguous.
  4. Submit the conclusion that the current evidence supports. Only then does the activity reveal the mystery pattern and its scope limit.

Use the high-substrate region deliberately. The NIH assay guidance notes that measurements above Km improve separation of competitive behavior from other patterns.
