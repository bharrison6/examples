    How it works

    Guide

    One game · three sources of skill

    Ask one question throughout: where does this opponent’s skill come from? The three tabs compare written instructions, experience stored as scores, and neural-network weights—adjustable numbers reused to score many board positions. They are different mechanisms, not difficulty levels.

    1. 1a · Rules-based intelligence. Play once and watch the highlighted rule explain each reply. Compare First 2 with All 8. A person supplied every move priority; playing more games cannot change them.
    2. 1b · Machine learning. Use Show move scores in Era 0, train 5,000 games, then compare the new era with Era 0. Outcomes update a stored score for each board position.
    3. 1c · Neural networks. Choose Create learning examples, then train the network. Compare error on practiced examples and held-out positions—positions kept out of training—then check playing results separately.

    The full rule set and a sufficiently trained table can both play unbeatable tic-tac-toe. People wrote the first opponent's move priorities directly; the second learns its priorities through games. The same exhaustive search checks each displayed policy before the app calls it unbeatable.

    Show move scores (stages 1b and 1c) prints the value it has learned or predicted for every empty square — gold looks promising to it, red-orange looks dangerous. Era 0’s learned scores are all zero. The dropdown lets you go back and play any earlier era.
