〰 Wavelet Lab

A reconstruction workspace for Haar wavelets

Represent it. Remove some. Rebuild it.

Haar wavelets separate an eight-value signal or a grayscale image into a coarse trend and localized details. Start with a prediction, switch coefficients on and off, then watch the reconstruction change.

pair (a,b) → normalized coarse coefficient (a+b)/√2   and   detail (a−b)/√2
Honest scope: this lab zeros coefficients and reconstructs. It does not quantize, encode bits, denoise, or promise a file-compression ratio.

Try this first

  1. Use Coarse only on the signal. Predict what disappears.
  2. Turn one detail back on. Which values or region changes?
  3. Move the image budget. Look for the first visual feature that returns.

The image keeps the largest-magnitude coefficients. That minimizes squared error for this orthonormal representation, but not necessarily perceived visual quality.

3 · New case: make a prediction before the answer

Two omitted detail coefficients have values 5 and −2. In this orthonormal representation, how much squared reconstruction error do they contribute together?




Answer: 29. Omitted orthonormal coefficients contribute their squared values: 5² + (−2)² = 25 + 4. The signs do not cancel in squared error.

Now explore the image without a scored visual claim: set Portrait to 64 coefficients. Name one feature that remains and one that fails. Then raise the budget until the eyes become recognizable.

Explain your observation using scale and the particular image. A large coefficient minimizes squared error contribution; it does not by itself guarantee that a feature is meaningful or perceptually important.

How to use Wavelet Lab

  1. Predict. For the eight-value signal, try “coarse only” before looking at the reconstruction.
  2. Try. Change the eight inputs or toggle a coefficient card. A retained card participates in the inverse transform; an omitted one becomes zero.
  3. Explain. Coarse coefficients carry broad shape. Details correct differences at increasingly fine scales.
  4. New case. In the image workspace, vary the honest coefficient count and compare reconstruction with raw numerical error.

All transforms here are orthonormal Haar transforms on power-of-two data. The runtime is self-contained and needs no network.

Presenter notes · 20 minutes

  • Hook: ask students whether a blurred reconstruction has “lost information” or merely omitted a representation component.
  • Demo: start at coarse only; bring back one detail and have the room name the changed region before you explain it.
  • Precision: emphasize that selecting largest magnitudes is optimal for squared error here. It is not a claim about what looks best, file size, or denoising.
  • Debrief: ask why a high-contrast boundary can be visually important even when a broad region carries more total energy.
