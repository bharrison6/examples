# Examples

A collection of small, self-contained browser demos. Each demo is plain HTML/CSS/JavaScript with no build step — open the demo's `index.html` in a browser (or open the root `index.html` for a launcher page).

## Demos

| Demo | Description |
|------|-------------|
| [tic-tac-toe](tic-tac-toe/) | Nine Board Tic Tac Toe — nine independent boards, pass-and-play, and CPU modes. Best of nine boards. |
| [snake](snake/) | Classic snake on a canvas — arrow key / WASD controls, score, and increasing speed. |
| [memory-match](memory-match/) | Card-flip matching game with a moves counter and timer. |

## Adding a new demo

1. Create a new folder with an `index.html` (keep it self-contained if possible).
2. Add a row to the table above and a card to the root `index.html` launcher.
