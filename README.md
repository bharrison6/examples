# Examples

Curated as the live demo tour for **"AI: From Zero to Takeoff"** — Bryant Harrison, Murray State University. The root `index.html` is the master launcher, in presentation order, with a QR code that points at the hosted copy.

A collection of small, self-contained browser demos. Each demo is plain HTML/CSS/JavaScript with no build step — open the demo's `index.html` in a browser (or open the root `index.html` for a launcher page).

## Demos

| Demo | Description |
|------|-------------|
| [fuel-golf](fuel-golf/) | Orbital mechanics golf for physics class — real integrated gravity, impulsive and finite-thrust burns, eight missions teaching the Oberth effect and perigee kicks. Includes a printable teacher guide. |
| [bridge-works](bridge-works/) | **Bridge Works** — truss bridge builder for physics class. Real direct-stiffness truss solver, live tension/compression colouring, Euler buckling, progressive collapse, six levels with golf-style par budgets. Includes a printable teacher guide. |
| [ladder-lab](ladder-lab/) | **Ladder Lab** — PLC trainer for the classic stoplight program. Genuine input-scan → solve-rungs → output-scan cycle with single-scan step mode and live image tables, AB-style instruction set (XIC/XIO/OTE/OTL/OTU/ONS/TON/TOF/CTU/CTD/RES), animated 4-way intersection wired to the I/O, seven built-in programs, a constrained ladder editor with four auto-graded challenges, and eleven injectable faults for troubleshooting practice. Includes a printable teacher guide. |
| [topping-out](topping-out/) | **Topping Out** — competitive construction scheduling for CM class. Real precedence-diagram CPM recomputed every turn (forward/backward pass, total and free float, FS/SS/FF with lags), a computed critical path that shifts and announces itself, non-compressible cure and inspection holds, trade stacking, a sourced overtime decay curve, and a seeded event deck so every team faces the identical run of bad luck. 4D cutaway, Gantt and network views, week-by-week debrief. Includes a printable instructor guide. |
| [glass-box](glass-box/) | **Glass Box** — how modern AI works, in three acts, for educators. Act 1 trains a real 42,458-parameter transformer from scratch in the browser — live loss curve, frozen era checkpoints (gibberish → words → sentences), real attention heatmaps you can tap, weight-matrix inspection, a temperature playground. Act 2 builds a reasoning model: two same-size brains trained with and without chain-of-thought on the same problems (54% vs 96% on the shipped run), an answer-key-free verifier that buys accuracy with test-time compute (60→78% from 1 to 8 attempts), and STaR-style self-improvement rounds where the model trains on its own certified work (49→85%). Act 3 is an agent: a real tool loop — genuine calculator errors and recovery, genuine document search, a context meter — where you can play the model yourself, and shrinking the context window genuinely breaks it. The engine computes its own transcendentals so seeded runs reproduce bit-for-bit on every device. Includes a printable presenter guide. |
| [zero-to-unbeatable](zero-to-unbeatable/) | **Zero to Unbeatable** — a single-file, phone-first demo of how machines learn. Tabular reinforcement learning that starts from zero knowledge and plays uniformly at random, trained in visible 5,000-game bursts between which the student plays it; frozen eras with per-era scoreboards, a brain inspector that overlays the learned value of every square, a "what it learned" card with before/after heatmaps of landmark positions, and an ending the app proves by searching every reachable game line rather than sampling. A second act trains it on nine boards at once — a mark per turn on any unfinished board, first to five boards — to show what breaks when the world gets bigger: on one board a position recurs 10x per training burst, on nine it recurs 1.06x, so no table could ever learn it. No network, no AI service, nothing baked in. Includes a printable demo guide. |
| [takeoff](takeoff/) | **Takeoff** (formerly Undershoot; internal module names keep the old word) — a phone-first, single-file presentation about machine capability since ChatGPT. The audience draws five benchmark forecasts before the real curves are revealed, explores a timeline of 123 model releases, and examines evidence across biology, medicine, weather, materials, mathematics, and software — with failures and overclaims kept beside the results. Every number resolves to a local source, and the demo includes a playable grid puzzle, live dataset self-test, presenter mode, and printable presenter guide. |
| [should-have-known-that](should-have-known-that/) | **Should Have Known That: Engineering Edition** — slider-based estimation trivia game for engineering students. 40 verified questions, 8 each across Statics & Mechanics, Materials, Electrical, Fluids & Thermo, and Everyday Engineering; linear sliders scored by percent error, logarithmic sliders (resistivity, speed of light, lethal current...) scored by order-of-magnitude error, with Bullseye/Close/Warm/Cold/Way Off bands. Animated guess-vs-truth reveal with a one-line "you should have known that because..." anchor for every number. Solo or 2–4 team pass-and-play with editable names and a running scoreboard; end screen calls out the sharpest and most should-have-known guesses. Single self-contained file, phone-first, works offline; the question bank is a commented array at the top of the file for instructors to edit. |
| [the-stranger](the-stranger/) | **The Stranger** — why prompts work, for a classroom. A student's question sits beside three toggleable blocks — context, success spec, expert keywords — and all 64 combinations across four scenarios are hand-written answers baked into the file, ~25,700 words, with a gate that fails the build if any two share more than 5% of their sentences. The levers-off answers are deliberately competent and aimed at nobody, so the room cannot dismiss the demo as rigged. Two stage mechanics: a target deck living inside lever 2 that deals itself a card whenever nobody has said what a finished answer looks like, and a jargon meter that counts the expert terms the student never typed (0–4 with the keyword lever off, 15–20 with it on). Class scoring plots usefulness against levers pulled, plus a self-paced student walkthrough with quizzes. Includes a printable presenter sheet and eight cut-out target cards. |

## Adding a new demo

1. Create a new folder with an `index.html` (keep it self-contained if possible).
2. Add a row to the table above and a card to the root `index.html` launcher.
