# Examples

Classroom example projects by Bryant Harrison, Murray State University. The root `index.html` is the demo gallery, with a QR code pointing at the hosted copy (`bharrison6.github.io/examples`).

The AI teaching content and its six interactive lessons have moved to [CourseWiki](https://bharrison6.github.io/coursewiki/artificial-intelligence/understanding-artificial-intelligence.html?p=ai-from-zero-to-takeoff). Their complete editable sources, original model/data code, tests and guides live in CourseWiki's `activities/` tree. The six original folders here preserve published URLs with redirects; the eleven classroom examples below continue to run here.

A collection of small, self-contained browser demos. Each demo lives in its own folder named with its title slug and opens from that folder's `index.html`, fully offline at runtime (no network, no AI inference). Some demos are built from `src/` by a per-demo `build.js`; the committed `index.html` is always the runnable output.

Every demo carries a `demo.json` manifest — identity, provenance (`built_with`), and compliance against the [demo contract](CONTRACT.md). The table below and the launcher card bodies are **generated** from those manifests — edit the manifest, not the table, then run `node tools/build-hub.js`.

## Adding a new demo

1. Create a folder named with the demo's kebab-case **title slug** (e.g. `bridge-works`). Folder names are public URLs on the hosted copy — never rename a shipped demo.
2. Meet the [demo contract](CONTRACT.md): self-contained `index.html`, `README.md`, printable guide, `?` Guide button, Settings with Open Presenter Notes + Presentation mode + Reset, presenter notes single-sourced with the printable guide, theme + attribution, mobile capable, offline.
3. Write `demo.json` (copy a neighbor's; record `built_with` provenance honestly).
4. Add the demo to a tour in `tours/` and drop a stub card `<a class="card" href="<slug>/index.html"></a>` where it belongs in `index.html`.
5. Run `node tools/build-hub.js` — regenerates this table and the launcher cards, validates declared files, prints the compliance report.
